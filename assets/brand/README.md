# Talos brand assets

- Mascot: "Little Talos", a round bronze robot in Greek black-figure style, Pleased expression (app icon). Beaming = success state. Worried = error/offline.
- `talos-icon-1024.png`: master icon. Also 512, 192, 32, 16, `apple-touch-icon.png` (180), `talos-icon-maskable-512.png` (80% safe zone), `favicon.ico`.
- `*-source.png`: the original Codex renders (OpenAI image generation, 2026-10-28).
- Palette: terracotta `#D9692B`, black-figure `#141110`, cream line `#F3E6CF`, ichor glow `#FFB15C`.
- `thread-icons/`: black-figure thread icons (projects, work, errands, reading, inbox, general), 512 px PNG with alpha, Codex renders 2026-10-28. They replace emoji in the thread list and tabs; keep them readable at 28 px.
