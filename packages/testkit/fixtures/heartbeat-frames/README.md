# heartbeat-frames

The `result` of a `heartbeat.test_result` as the app reads it, one file per case, all for the config in `config.json`
(its `config_hash` is `configHash()` of that file's `config`; a test checks this).

These are contract fixtures written from the protocol's own builders, not recorded from a real bridge.
`06` is deliberately wrong in ways a newer Mac might be.
