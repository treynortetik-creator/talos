# ERRORS — things that broke

Commands that failed, tools that misbehaved, output that was wrong.

    ## YYYY-MM-DD — one-line title
    **What happened:** the actual error text, not a paraphrase.
    **Root cause:** ...
    **Fix applied:** ...
    **Rule:** how to avoid it next time.

**Diagnose before you declare.** Check your own inputs first — a wrong working
directory and a rate limit both look exactly like "the tool is broken," and
reporting a healthy tool as broken burns trust you will want later.
