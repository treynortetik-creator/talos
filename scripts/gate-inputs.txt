# The gate's own inputs: the ONE list (scripts/gate-inputs.test.ts checks it), of every file the gate sources, runs, or reads its
# verdict from. Read in three places, always from main's copy and never from the change being judged:
#   - gate-push.sh's rebase-clean pass (the gate passed, main moved, the rebase was clean, and no new main commit touches a file
#     of this change) pushes after the cheap checks only when no new main commit touches a path matching a line here; otherwise
#     the full gate runs again (docs/CI-MACHINES.md);
#   - a handoff (refs/heads/handoff/<machine>/<name>) that changes a path matching a line here is refused, by the pre-push hook
#     when it is pushed and by gate.sh --push --from when it is landed: the landing machine would run the handoff's own gate.
# One extended regex per line, matched against the whole repository path; lines starting with # are comments. Paths are matched
# folded as a Mac's disk compares them (scripts/path-fold.sh: Unicode case, composition), and every line is case-blind.
# It fails closed: everything under scripts/ and .github/workflows/ counts, so a gate file added later is an input already.
# One reader makes an exception: the fast gate (scripts/gate-fast.sh) lets a test file (*.test.ts, *.test.tsx, *.spec.ts, Swift
# Tests/) through when no other line here names it, because a test is not the code it checks. The handoff and rebase-clean rules
# above keep every line as it is.
^scripts/
^\.github/workflows/
^\.githooks/
(^|/)package\.json$
^pnpm-lock\.yaml$
^pnpm-workspace\.yaml$
(^|/)tsconfig[^/]*$
(^|/)biome\.jsonc?$
(^|/)vitest\.[^/]*(config|workspace)\.[^/]+$
^vitest\.run-tmp\.ts$
(^|/)vite\.[^/]+\.[cm]?ts$
(^|/)playwright\.config\.[^/]+$
^\.nvmrc$
^\.npmrc$
# pnpm runs a .pnpmfile.cjs on install, before any test
(^|/)\.pnpmfile\.cjs$
(^|/)bunfig\.toml$
# the related-test picker's helpers outside scripts/: the bridge suite's own runner, the web specs' port helper the config reads
^apps/bridge/scripts/
^apps/web/test/helpers/pw-port\.ts$
# the runners' setup files: Vitest's globalSetup and setupFiles, Playwright's globalSetup
(^|/)(global-setup|setup-clock)\.ts$
# the bridge suite's preload (bunfig.toml) and the two test-only files it loads: they keep every bridge test off the owner's live
# Chronos and real claude, and run before each test file
^apps/bridge/test/(preload|run-tmp|fake-claude)\.ts$
# biome lints with the .gitignore files (biome.json vcs.useIgnoreFile): a line there takes files out of the lint step
(^|/)\.gitignore$
# Swift packages: a Swift suite run on a landed tree evaluates the manifest and runs its build plugins before any test
(^|/)Package\.(swift|resolved)$
# git attributes change what git writes to disk at checkout (eol, working-tree-encoding) and how it diffs (Fable R1-3)
(^|/)\.gitattributes$
# the paths the guards protect: the fast gate (gate.sh --fast) runs the full gate for a change to any of them
^docs/protected-paths\.txt$
