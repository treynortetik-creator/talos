# The test folder prefixes scripts/tmp-sweep.sh removes from $TMPDIR once a day old: one per line, a name start ending in "-"
# (letters, digits, "." "_" "-"; a "!" line may hold a space too). Only these are ever swept: $TMPDIR can be the machine's shared one, where the live Talos app and
# other tools keep their own folders. A line starting with "!" is a prefix a test makes that is deliberately NOT swept (too
# generic to be sure a folder of that name is a test's); give that test a talos- name to have its leftovers swept.
# scripts/tmp-sweep.test.ts fails when a test makes a folder directly in the temp folder with a prefix that is on neither list.
