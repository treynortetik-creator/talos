# fails alone too refuses as it always did. The gate reads this list from the base it measures the change against (main as
# fetched), never from the working tree: a change cannot add its own flake, and a new entry counts after it lands on main.

#   <path from the repository top> TAB <test name as the runner prints it: "describe > test"> TAB <owner> TAB <until YYYY-MM-DD>

# and refuses), so a flake is fixed or its entry is renewed in a reviewed change. Evidence stays in <cache>/logs/flakes.tsv;
# each rerun is logged in <cache>/logs/flake-reruns.tsv. Lines starting with # and empty lines are ignored.
